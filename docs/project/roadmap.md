# Roadmap

## v0.3 beta — current implementation

Graph-native local orchestration: approved DAGs, independent worker loops, worktree isolation, journal recovery, bounded integration repair, model gateway, event-based dashboard and legacy migration. See [architecture](../architecture/index.md).

## v0.3 stable gates

Complete the [release readiness](v0.3-readiness.md) checks: critical modules at 90% lines and branches, all supported CI platforms, authenticated provider conformance, operational interruption scenarios, provenance audit and independent baseline comparison.

## Later work

Model-specific capability negotiation, provider-session continuation, intermediate-input conflict automation, richer context attachments and narrowly scoped mid-run clarification follow the same approval and evidence invariants. Remote execution remains an interface extension, not a dependency of local Ralph.

Version numbers do not substitute for verified behavior. Broader concurrency and routing changes require repeatable quality, time and cost evidence.
