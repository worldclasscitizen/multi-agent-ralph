# Ralph 0.3.0

[English](https://github.com/worldclasscitizen/Ralph/blob/v0.3.0/README.md) · [한국어](https://github.com/worldclasscitizen/Ralph/blob/v0.3.0/README.ko.md)

Ralph now executes dependencies as a local DAG while retaining an iterative Ralph Loop inside each writing node. Runs preserve input commits, verification evidence, revision history and explicit recovery decisions.

- Isolated Git worktrees, bounded parallel execution and verified integration that preserves user changes.
- Durable event journal, interruption inspection, resumable runs and idempotent result delivery.
- Unified provider policy, explicit model pins, bounded retries and evidence-scoped support.
- Packaged graph dashboard with node inspectors, revision history and provider usage views.
- CLI approval, clarification and migration that retains v0.2 history and credentials.
- Separate signed catalog v2; original signed catalog retained for older clients.

Install with npm install -g @worldclasscitizen/ralph@0.3.0. Node.js 22 or 24 and Git are required. Start with ralph init, then ralph plan and review the exact plan before ralph run --plan RUN_ID --yes.

This changes the execution API: v0.2 approval hashes and sessions do not authorize v0.3 graphs. Run ralph migrate --to 0.3 --dry-run before migration. See the migration guide in the package. Remote execution and consumer auto-push/deployment are outside this release.

Release evidence identifies the exact tested commit, archive, provider/model/environment, six CI cells, process interruption cases and natural-language graph execution through final delivery. Earlier baseline comparison attempts remain historical reference. Compatible providers have no current live verification claim. No general quality, speed or cost superiority is claimed.

## 한국어 변경 사항

작업 의존성을 DAG로 실행하고 각 쓰기 노드 내부에는 기존 Ralph Loop를 유지합니다. 독립 worktree, 검증 후 통합, 이벤트 원장, 중단 점검과 재개, 그래프 대시보드, 공급자 공통 정책을 제공합니다. 사용자 변경이 있으면 결과 브랜치를 보존하고 자동 반영을 보류합니다.

npm install -g @worldclasscitizen/ralph@0.3.0으로 설치합니다. Node.js 22 또는 24와 Git이 필요합니다. ralph init 후 ralph plan으로 계획을 확인하고 동일한 계획을 승인해 실행합니다. 이전 이력과 자격 증명은 유지하지만 새 실행에는 새 그래프 승인이 필요합니다. 전환 전 ralph migrate --to 0.3 --dry-run을 사용합니다.

출시 보고서에 코드·패키지 무결성, 운영체제별 검사, 실제 공급자와 모델 범위, 중단·복구 및 자연어 그래프 생성부터 결과 반영까지의 검증을 기록합니다. 이전 비교 시도는 참고 이력으로 보존합니다. 실검증되지 않은 공급자의 지원 등급은 compatible 또는 experimental입니다. 일반적인 품질·속도·비용 우위를 주장하지 않습니다.
